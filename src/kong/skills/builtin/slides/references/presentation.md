# Presentation handling
Presentation(path) loads a template; Presentation() creates a default deck.
Use existing layouts and placeholders where possible. Replacing all text can discard intentional formatting.
For charts and tables, verify values against inputs. An image of a chart is not an editable chart.
Set text sizes and object positions deliberately; a small text box does not automatically guarantee fit.
The inspector lists text from shapes and table cells, with bounds. It does not extract every chart, image, group or speaker note.
Saving and reopening proves basic structural readability. It does not prove visual quality.
